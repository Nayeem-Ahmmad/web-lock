Web Lock Settings

Changes apply to new tabs opened after saving.

Behavior

"Once per N minutes" means that after unlocking, new tabs open without a password for N minutes. It always resets when the browser is closed.

Change password

Recovery key

Generate a new key if you lost the old one. The old key stops working immediately.

Web Lock stores only salted hashes of your password and recovery key, on this device. Nothing is sent anywhere. Web Lock locks new tabs in normal windows. It does not lock tabs that are already open, Incognito windows, or protect against someone who removes the extension. Lock your computer (Win + L) when you leave your desk.
